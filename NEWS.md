# forenseqhaplo 1.0.0

## Initial public release

* Processes individual or folder-based `ForenSeq` flanking-region reports.
* Assigns sequence-based iSNP haplotypes using a bundled or user-supplied database.
* Applies configurable read-depth and allele-balance thresholds.
* Produces `Familias`-compatible haplotype and optional TargetSNP outputs.
* Generates per-sample review workbooks, processing logs and parameter records.
* Supports DVI relationship columns and replicate consensus profiles.
* Includes two fully synthetic reports and one fully synthetic DVI relationships file for documentation and testing.
